LanguageTool is an open-source proofreading tool for English, French, German, Spanish, Portuguese, Dutch, and many other languages. It detects grammar, style, and spelling errors that a simple spell checker cannot find, such as subject-verb agreement problems, incorrect articles, and commonly confused words.

## Deployment

### Podman Compose

```yaml
services:
  languagetool:
    image: "ghcr.io/daemonless/languagetool:latest"
    container_name: languagetool
    environment:
      - PUID=1000  # User ID for the application process
      - PGID=1000  # Group ID for the application process
      - TZ=UTC  # Timezone for the container
      - JAVA_OPTS=-Xmx512m  # JVM memory and runtime options (default: -Xmx512m)
      # - LANGUAGETOOL_PORT=  # Port to bind HTTP server to (default: 8010)
    volumes:
      - "/containers/languagetool:/config"
    ports:
      - "8010:8010"
    # always (not unless-stopped) so FreeBSD's podman rc.d auto-starts it at boot
    restart: always
```

Save as `compose.yaml`, then run `podman-compose up -d`.
